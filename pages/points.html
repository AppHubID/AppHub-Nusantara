AppHub Points

AppHub Points adalah sistem poin yang akan menjadi penghubung antara aktivitas pengguna dan reward di ekosistem AppHub.ID.

Apa itu AppHub Points?

AppHub Points adalah satuan poin internal yang nantinya dapat dikumpulkan pengguna AppHub.ID melalui berbagai aktivitas di dalam ekosistem. Points berfungsi sebagai jembatan antara keikutsertaan pengguna dengan reward yang bisa mereka peroleh.

Sistem ini masih dalam tahap perancangan. Halaman ini memberikan penjelasan konsep, bukan sistem saldo nyata. Saat ini tidak ada saldo pengguna yang benar-benar tersimpan.

Kegunaan

Untuk apa Points digunakan

Points akan berguna untuk berbagai hal di ekosistem AppHub.ID.

Menukar Reward

Points dapat ditukar menjadi reward di Reward Center — seperti diskon, benefit, atau Gift Code eksklusif.

Potongan Pembelian

Points akan dapat digunakan sebagai potongan harga saat berlangganan paket AppHub.ID.

Membuka Konten Khusus

Sejumlah konten atau aset eksklusif akan dapat diakses dengan Points.

Cara Mendapatkan

Bagaimana Points diperoleh

Beberapa cara yang akan memungkinkan pengguna mengumpulkan Points.

Pembelian Paket

Setiap paket langganan AppHub.ID akan memberikan sejumlah Points sesuai tingkatan paket.

Referral Berhasil

Setiap referral yang berhasil akan memberikan bonus Points kepada pengaju referral.

Program & Event

Keikutsertaan dalam program atau event resmi AppHub.ID dapat memberikan Points tambahan.

Gift Code & Kupon

Sejumlah Gift Code atau kupon tertentu akan memberikan bonus Points.
